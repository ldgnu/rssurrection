Falta conectar FreshRSS

RSSurrection lee tus feeds desde tu propia instancia. Se configura por variables de entorno, nunca desde el navegador.

VariableQué es
FRESHRSS_BASE_URLURL de tu FreshRSS. Alcanza con el host: se agrega /api/greader.php solo.
FRESHRSS_USERUsuario de FreshRSS.
FRESHRSS_API_PASSWORDContraseña de API del perfil (Perfil → API), no la del login.

Cómo levantarlo

cp .env.example .env
$EDITOR .env
docker compose up -d --build
